Before → After

저녁마다 하던 정리가 사라집니다

01

"마감하고 엑셀 정리 30분…"

→ 팔릴 때 한 줄이면 끝. 매출·재고·마진이 그 자리에서 장부에 정리됩니다. 반품·교환도 말로 하면 됩니다.

02

"발주한 거 얼마나 안 왔더라?"

→ 매일 아침 AI가 먼저 보고합니다. 늦고 있는 발주, 떨어져가는 재고, 거래처에 줘야 할 돈, 카드사에서 덜 들어온 정산까지.

03

"이번 달 얼마 남았지?"

→ 채팅으로 물어보면 반품 빼고 원가 따져서 바로 답합니다. 월간 리포트엔 부가세 예상액까지.

Workflows

실제로 이런 일이 자동화됩니다

판매 한 줄
어떤 상품인지 알아듣고 매출 기록 + 재고 차감 + 그 시점 원가로 마진 계산. 반품·교환은 장부를 고치지 않고 새 줄로 남깁니다.
매일 아침 브리핑
묻기 전에 먼저 보고 — 오늘 일정 · 늦고 있는 발주 · 품절임박 · 줘야 할 돈 · 정산 차이 · 어제 매출. 저녁엔 마감 보고가 빠뜨린 기록을 물어봅니다.
발주 → 입고
발주를 걸어두면 물건이 들어올 때마다 얼마나 안 왔는지 자동 계산. 나눠서 들어와도 추적됩니다. 상품마다 정한 기준 이하로 재고가 떨어지면 품절임박 경고.
자사몰 주문 파일
쇼핑몰 관리자에서 받은 주문 CSV를 그대로 던지면 알아서 정리. 같은 파일을 두 번 올려도 이중 기록이 안 생깁니다. 카페24는 자동 연동 준비 중.
회의 녹음 업로드
녹음을 내 컴퓨터 안에서 글로 옮기고(외부 서버로 안 나감) 요약·결정사항·할 일을 정리해 일정에 등록합니다.
"마감하자"
오늘 매출 요약 + 빠진 기록 확인 + 내일 일정. 월간 리포트는 채널·브랜드별 순매출, 드롭 소진율, 부가세 예상액까지.

Notion

Ledger Discipline

템플릿이 아니라 규율입니다

예쁜 장부는 많습니다. 이 킷의 가치는 숫자가 틀어지는 길목을 미리 막아두는 데 있습니다.

  • 지우개 없는 장부 (append-only)과거 기록은 절대 고치지 않습니다. 정정·반품·교환 전부 새 줄 — 숫자의 근거가 사라지지 않습니다.
  • 그때 원가로 그때 마진 (원가 스냅샷)판 순간의 사입가를 함께 적어둡니다. 다음 시즌에 사입가가 올라도 지난달 마진이 바뀌지 않습니다.
  • 실수로 두 번 보내도 안전 (멱등키)같은 메시지, 같은 파일이 두 번 처리돼도 기록은 한 번만 남습니다.
  • 안 맞으면 바로 보입니다 (자동 대조)발주와 입고, 주문과 품목 합계, 장부와 실입금 — 어긋나는 순간 자동으로 표시됩니다.
  • 재고는 고치지 않고 흔적으로 (실사조정)실사에서 1개가 비면 숫자를 고치는 게 아니라 "실사조정 −1" 한 줄을 남깁니다.
Get Started

10분 설치

개발을 몰라도 됩니다 — 아래 네 줄을 순서대로 붙여넣으면 끝. 막히는 단계가 있으면 저장소의 설치 가이드가 하나씩 안내합니다.

# 1. 내려받기 git clone https://github.com/kinkos1234/select-shop-kit && cd select-shop-kit # 2. Notion 연결 열쇠 발급 (notion.so/my-integrations) 후 허브 페이지에 연결 export NOTION_TOKEN=ntn_xxx # 3. 장부 13권 + 대시보드 자동 생성 python3 setup/create_databases.py <페이지 ID> --staff "대표,직원A,직원B" # 4. AI 스킬 설치 ./install.sh
정직한 한계 — Notion을 장부로 쓰는 구조라 월 수백 건 규모까지가 적정선입니다. 월 주문 300건 이상, 반품 월 10건 이상이 되면 전용 데이터베이스 이전을 검토하세요. 판단 기준은 저장소 문서에 있습니다.
